# 一、最重要的问题：IC t-stat 计算是错的

你写：

> IC t-stat = -1.02 < 2

但你前面说：

> 反转后 IC = +0.54

如果 IC = +0.54，t-stat 不可能是 -1.02。

说明：

* 你 **可能用未反转 IC 的时间序列算 t-stat**
* 或者 IC 序列符号和 summary 不一致
* 或者样本数量 N 用错

---

## 正确做法

t-stat 必须基于 **rolling IC time series**

比如：

```python
# 每周一个IC
ic_series = [...]

ic_mean = ic_series.mean()
ic_std = ic_series.std()
t_stat = ic_mean / (ic_std / np.sqrt(len(ic_series)))
```

注意：

* 不能用整体 corr 算一次然后当成样本
* 不能用单个 IC 值算 t-stat
* N 应该是 “时间点个数”，不是样本数

如果你只有 520 个预测点，但 IC 是整体算的，那是错误统计。
