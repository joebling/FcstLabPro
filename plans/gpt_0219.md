# 四、核心优化方向（按优先级排序）

---

# ⭐ 优化方向 1：重新定义 label（最重要）

你现在的问题本质是：

> 模型预测的不是“未来收益”，而是某种趋势概率。

建议做：

### 改为回归模型

不要预测 0/1

改成：

```
future_14d_return
```

直接预测未来14天收益率。

然后：

* 排序选 top quantile
* 或 >0 才入场

这会大幅减少“反转问题”。

---

# ⭐ 优化方向 2：分 regime 训练（强烈建议）

目前你是统一模型。

应该拆成：

```
Bull Regime 模型
Bear Regime 模型
Sideway 模型
```

用 MA200 或趋势指标先判定 regime，再调用不同模型。

否则模型在不同市场状态学到相互冲突的模式。

---

# ⭐ 优化方向 3：概率校准（你现在概率明显失真）

Bull 概率只有 5%

说明：

* 模型严重偏向某一类
* 输出概率没有 calibration

建议：

```
Platt scaling
Isotonic regression
```

做概率校准。

否则 0.5 阈值没有意义。

---

# ⭐ 优化方向 4：不要固定 14 天持仓

固定持仓是“掩盖信号不稳定”。

建议改为：

* 动态止盈（2x ATR）
* 动态止损（1x ATR）
* 或 trailing stop

否则收益靠运气。

---

# ⭐ 优化方向 5：增加 regime 特征

你现在用：

* MA50
* MA150
* MA200

太简单。

可以加入：

* realized volatility
* funding rate
* open interest 变化率
* stablecoin inflow
* market breadth

你的模型目前是 price-only，很难稳定。

---

# ⭐ 优化方向 6：Walk-forward 验证

你现在 fold 数变化（21 → 24）已经说明：

> 数据结构改变。

建议做：

```
rolling 2y train
6m test
walk-forward
```

看不同年份表现。
