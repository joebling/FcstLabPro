# 二、关键问题：你在做的是二分类 label

Label 定义：

> 跌幅 > 5% → label = 1

这是一个 threshold event。

IC 的含义变了。

你不是在预测连续收益排序，
你在预测：

> “未来21天是否出现 >5% 下跌”

这其实是：

* 事件预测
* 不是真正排序 alpha

这会天然抬高 IC。

因为：

* 大跌往往发生在趋势阶段
* 技术指标很容易抓住

所以 IC 0.65 并不等于“真实收益排序能力 0.65”。
