# 模型结构重构
很好，我们直接进入 **模型结构重构**。

这次不谈策略过滤，不谈 MA，不谈持仓。

只解决一个核心问题：

> 如何让模型本身产生稳定 alpha，而不是靠规则补救。

我会给你一个 **可直接落地的模型结构蓝图**。

---

# 一、先明确你现在模型的结构问题

你当前结构：

* 任务：reversal 二分类
* Horizon：T=21
* 输出：bull_prob
* 模型：Orion-BiX 表格神经网络
* 特征：148 个
* 结果：必须反转才能赚钱

核心问题：

1. 二分类丢失收益强度信息
2. 标签与交易目标不一致
3. 特征过多，信号密度低
4. 概率分布塌缩
5. regime 没有结构化使用

---

# 二、重构目标

我们构建一个：

> Regime-aware Return Regression Model

核心原则：

1. 预测收益，不预测方向
2. 模型输出强度，而不是买卖
3. 结构天然兼容币本位
4. 可以动态仓位

---

# 三、新模型结构（核心设计）

## 第一层：Regime 分层（结构层，而不是特征）

不要把 regime 当普通 feature。

要做：

```
if regime == bull:
    使用 BullRegressionModel
elif regime == bear:
    使用 BearRegressionModel
else:
    使用 SidewayModel
```

regime 判定可以用：

* MA200 slope
* realized vol
* funding rate
* 或简单 HMM

重点：

> 不同市场状态训练不同模型。

这是你现在缺的。

---

## 第二层：任务定义（关键）

### 改成回归

标签定义：

```
y = log(close[t+21] / close[t])
```

或者更好：

```
y = future_21d_return - 21d_hold_return
```

（预测超额收益）

不要再用 reversal 分类。

---

## 第三层：输出结构

模型输出：

```
predicted_return
predicted_volatility (可选)
```

如果高级一点：

做双头输出：

* 均值
* 方差

变成：

> 分布预测模型

---

## 4️⃣ Regime 因子（只用于分层，不喂给模型）

# 六、损失函数设计（关键）

普通 MSE 不够。

建议：

### 1️⃣ IC 优化损失

最大化：

```
corr(pred, y)
```

或加入 rank loss。

---

### 2️⃣ 加入 downside penalty

例如：

```
loss = MSE + λ * negative_return_penalty
```

强化熊市风险控制。

---

# 七、避免你再次翻车的结构保护

## 1️⃣ Walk-forward 训练

```
Train: rolling 2y
Test: next 6m
```

而不是全样本。

---

## 2️⃣ 年度 IC 监控

输出：


---

## 3️⃣ 输出分布监控

实时监控：

```

```

防止概率塌缩。
