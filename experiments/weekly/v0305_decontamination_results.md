# v0305 去污染实验结果

## 📝 核心结论

### ✅ 去污染成功：模型预测能力是真实的

去除污染特征后，**Kappa 从 0.326 上升到 0.343**，说明：
1. 模型的预测能力**不依赖于特征-标签污染**
2. 移除污染特征反而减少了噪音
3. Top 特征从 `rsi_14`/`price_vs_sma_50` 变为 `funding_rate_14`/`volatility_20d` — 更合理

### ⭐ 最佳策略：E5 (X=3%, RSI=50, MA=50, 去污染)

- **Kappa = 0.343**（与 E1 持平）
- **F1 = 0.441**（比 E1 +6.5%）
- **Precision = 0.434**（比 E1 +9.6%）
- **F1=0 占比 = 41%**（比 E1 的 48% 下降）
- **正例率 = 14.7%**（比 E1 的 10.3% 显著提升）
