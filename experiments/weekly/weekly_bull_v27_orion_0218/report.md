### 11.5 策略逻辑

```python
# 三重MA过滤策略
hold_days = 13  # 持仓期

for i in range(n):
    if days_in_pos > 0:
        # 持有仓位
        y_hold[i] = current_pos
        days_in_pos -= 1
    elif y_bull[i] == 1:
        # 三重MA过滤: 同时站上 MA50, MA150, MA200
        if above_ma50[i] == 1 and above_ma150[i] == 1 and above_ma200[i] == 1:
            y_hold[i] = 1
            current_pos = 1
            days_in_pos = hold_days
        else:
            y_hold[i] = 0
    else:
        y_hold[i] = 0
```
