# 三、dip_recovery label 本身存在内生性问题

它定义为：

> 未来 T 天内 dip > 5% 且 recovery > 3%

这个定义非常关键。

它其实包含两个未来事件：

1️⃣ 先跌
2️⃣ 再反弹

而你的特征里包括：

* 技术指标（RSI, Bollinger）
* 结构特征
* regime
* FGI

问题来了：

> 这些指标本身就是围绕“超卖-反弹结构”设计的。

也就是说：

你的 label 和 feature 是高度结构相关的。

这会导致：

> 模型并不是在预测未来
> 而是在识别一种技术形态的未来延续性

这在统计上会非常“好看”。

但在真实交易里：

一旦市场结构变化，就会崩。
