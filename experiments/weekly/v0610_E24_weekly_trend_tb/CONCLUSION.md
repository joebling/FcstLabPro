# E24 周级别趋势确认模型 — 负结果结论 (2026-06-10)

## 一句话

**8 周 horizon 的无条件趋势三分类，OOS 没有可用 alpha。判噪音，不晋升。**

## 实验设计

- **标签**: Triple Barrier (T=56d), 动态 ATR×4 屏障 → {0=续跌, 1=趋稳横盘, 2=转势反弹}
- **标签分布** (探针确认均衡): 续跌 31% / 趋稳 24% / 转势 46%
- **验证**: walk-forward, step=purge_gap=T=56 (铁律 §2.1 非重叠), 37 folds, 2018-2026
- **模型**: LightGBM multiclass, 137 特征 (technical/volume/flow/market_structure/external_fgi)

## 结果 (OOS 汇总)

| 指标 | 值 | 手册门槛 | 判定 |
|------|----|---------|------|
| Cohen Kappa (pooled) | **-0.039** | >0 才有意义 |  噪音 |
| Accuracy | 0.346 | — | ≈ 随机(1/3) |
| f1_macro | 0.326 | — |  |
| per-fold Kappa 均值 | 0.059 | — | 微弱 |
| per-fold Kappa t-stat | 2.36 | >1.5 |  统计显著但效应量可忽略 |
| fold acc std | **0.28** | — |  极强 Regime 依赖 |

## 失败机理 (混淆矩阵)

```
              预测0   预测1   预测2
真实续跌(0)   264     30     385   ← 跌被当成涨的次数(385) > 判对(264)
真实趋稳(1)   125     91     262
真实转势(2)   404    150     361   ← 涨被当成跌的次数(404) > 判对(361)
```

**模型把相反方向(续跌↔转势)对称搞混约一半** → Kappa 归零。
趋稳(1)命中率 19% < 其基础占比 23% → 震荡期完全无法识别。
**非退化 bug**: 三类都在预测(793/271/1008), 分布跟随真实, 是真的在努力但学不到。

## 结论与建议 (手册 §3.3 / §4.2)

1. **不晋升、不上生产。** Kappa≈0 直接判死刑。
2. **失败模式 = Regime 依赖** (fold acc 0.00~0.95, std 0.28)。这正是手册 §4.2
   的典型症状: 单一无条件模型在不同 regime 下行为完全相反, 平均后归零。
3. **这恰好实证了项目哲学**: 多周级别的"未来"由 regime 主导, 不存在一个固定的、
   跨 regime 通用的趋势预测函数 —— 与 WolfyXBT "刻舟求剑"是同一个病根的两个版本
   (他用固定天数, 这里是固定无条件模型)。
4. **唯一可能的出路 (谨慎)**: regime 条件化。但我们【已经有】RR rolling-2y cycle gate
   (src/dashboard/data/cycle.py) 充当 regime selector, 它在这个 horizon 上已经是更
   合适的工具。再拆样本做 per-regime 模型会让本就偏薄的样本进一步稀释, 收益递减。
   **建议: 不继续投入 ML 趋势预测, 周级别定位继续用 RR gate。**

## 复用价值

- 证伪了"加个周级别 ML 预测模型"的直觉 (YAGNI 胜利)。
- Triple Barrier 三分类跑通了全套基础设施 (multiclass metrics/lgbm/walk-forward), 留作后人参考。
