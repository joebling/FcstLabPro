## 三大策略变体原理详解

三个变体共享同一套信号生成管线，区别在于「退出机制」和「环境过滤」两个维度的叠加。

### 0️⃣ 共享基底：信号生成管线

```
原始数据 (BTC 日线)
    │
    │  build_features()  ← 排除污染特征 (rsi_*, price_vs_sma_*, sma_cross_*)
    ▼
50+ 特征 (funding_rate, volatility, OBV, FGI, …)
    │
    │  LightGBM walk-forward (init_train=800, step=21, oos=63)
    ▼
每日预测: y_pred ∈ {0, 1}
    │
    │  重叠去重: 同一天被多个 fold 覆盖时，取最新 fold 的预测
    ▼
1218 个唯一日期的去重信号  (y_pred=1 共 139 次)
```

**y_pred = 1 的含义**: 模型认为当前处于「超卖低位」（RSI < 45 且 close < SMA50），未来 21 天内有 ≥ 4% 的反弹概率较高。

> 注意：RSI/SMA 过滤已从特征集中移除，模型不再「看到」这些指标。
> 它是通过 funding_rate、volatility、OBV 等独立特征“间接”捕捉超卖状态的。

### 1️⃣ E1 基础 (激进) — 固定持仓期

**设计思路**: 完全信任模型信号，信号触发即买入，持有完整 T 天后平仓，不做任何干预。

```
               信号日                         T=21天后
                │                              │
时间轴: ───────█═════════════════════█────────
                 └────── 持仓 ───────┘
                  position = 1              position = 0
```

**入场规则**:
- 当 `y_pred = 1` 时，当日以收盘价买入
- 如果当前已持仓（上一个信号还未过期），仓位自然延续，不重复开仓

**出场规则**:
- **固定 21 天后无条件平仓**，无论盈亏
- 不设止盈、不设止损

**成本模型**:
- 每次仓位变动 (空→多 或 多→空) 收取 0.1% 单边成本
- 一笔完整交易 = 0.2% (买入 0.1% + 卖出 0.1%)

**典型行为示例**:
```
日期          价格       信号    仓位    说明
2023-10-15   $27,100    1      1     RSI<45, <SMA50, 模型看多 → 买入
2023-10-16   $27,500    0      1     持仓中，+1.5%
2023-10-25   $34,200    0      1     持仓中，+26.2%
2023-11-05   $35,000    -      0     第 21 天，无条件平仓，最终 +29.2%
```

**优势**:
- 能完整捕捉大幅反弹 (如 2023-10 的 +29%)
- 最高暴露 (39.4%)，总收益最大
- 逻辑最简单，无任何人为干预

**劣势**:
- 不平仓意味着吃下全部反弹后的回调
- 熊市中仍会出信号 → 成为主要亏损来源
- MaxDD = -24.7%，来自 2022 熊市尾巴的几次误判

### 2️⃣ E1 + 止盈 (稳健) — 提前收割利润

**设计思路**: 标签定义是 「21 天内涨 ≥ 4%」，那么到达 4% 目标就是信号“兑现”了。无需继续持有，立即平仓降低暴露。

```
               信号日       到达+4%         T=21天
                │           │               │
时间轴: ───────█═════════█───────────·──────
                 └─ 持仓 ─┘
                    ↑ 只持到目标价，提前退出

对比基础版:
时间轴: ───────█═════════════════════█────────
                 └────── 全部持有 ───────┘
                    ↑ 包含反弹后的回调风险
```

**入场规则**: 与基础版完全相同。

**出场规则** (二选一，哪个先触发哪个生效):
- ✅ **止盈触发**: 价格相对买入价上涨 ≥ 4% (= 标签的 X 参数) → 立即平仓
- ⬜ **时间触发**: 如果 21 天内未触发止盈，到期无条件平仓 (可能亏损)

**典型行为示例**:
```
情景 A: 止盈触发 (赢)
日期          价格       信号    仓位    说明
2023-10-15   $27,100    1      1     买入
2023-10-20   $28,200    0      0     +4.06% ≥ 4% → 止盈平仓! 只持了 5 天
⇒ 结果: +4.06%, 暴露 5 天, 资金立即释放

情景 B: 时间触发 (未达目标)
日期          价格       信号    仓位    说明
2025-01-10   $92,000    1      1     买入
2025-01-15   $90,500    0      1     -1.6%, 未触发止盈
2025-01-31   $91,000    -      0     第 21 天, +达目标，到期平仓, -1.1%
⇒ 结果: -1.1%, 暴露 21 天
```

**为什么止盈有效?**

| 机制 | 解释 |
|------|------|
| **降低暴露** | 39.4% → 26.8%，场内时间减少 1/3 |
| **截断回吐** | 反弹达标后不再承担回调风险 |
| **加速资金周转** | 提前释放资金，可捕捉下一个机会 |
| **PF 提升** | 盈亏比从 1.25 → 1.26，小幅改善 |

**为什么总收益下降?**
- 基础版的 +109% 中，约 40% 来自「反弹超过 4% 后继续持有」的额外收益
- 止盈版在 4% 就平仓，放弃了这部分「尾部收益」
- 但同时也避开了「反弹后回调」的亏损，净效果是取舍

### 3️⃣ E1 止盈 + Regime (保守) — 熊市自动静默

**设计思路**: 在止盈基础上叠加环境过滤。熊市中「跌后反弹」大多是假反弹，
模型在熊市的 Kappa 只有 0.14，不如直接不出信号。

```
市场环境判断:
    rolling_return_63d = (close_today / close_63d_ago) - 1
    如果 rolling_return_63d > -10%  →  非熊市 → 允许交易
    如果 rolling_return_63d ≤ -10%  →  熊市   → 强制空仓


                       熊市区间                    非熊市区间
                │█████████████████│               │
信号:            ▲     ▲     ▲                  ▲        ▲
执行:           ✗     ✗     ✗                  ✔        ✔
                └ 全部被拦截，不下单 ┘         └ 正常执行 ┘
```

**完整决策流程** (每日执行):

```
Step 1: Regime 判断
│  计算过去 63 天滚动收益率
│  rolling_63d = (price_today / price_63d_ago) - 1
│
├─ 如果 rolling_63d ≤ -10%  →  熊市 → 强制 position = 0
│     └─ 即使模型发出 y_pred=1，也不执行
│     └─ 如果当前有持仓，立即平仓 (熊市中持仓 = 拿命)
│
└─ 如果 rolling_63d > -10%  →  非熊市 → 进入 Step 2


Step 2: 模型信号
│  检查 y_pred
│
├─ y_pred = 0  →  不操作
│
└─ y_pred = 1  →  买入，进入 Step 3


Step 3: 持仓管理 (每日检查)
│
├─ 价格相对买入价 ≥ +4%?  →  止盈平仓  ✔
├─ 持仓天数 ≥ 21?          →  到期平仓  ✔
├─ regime 变熊市?           →  强制平仓  ✔
└─ 否则                     →  继续持有  ⬜
```

**典型行为示例**:
```
情景 C: 熊市拦截 (避免亏损)
日期          价格       63d收益   信号    仓位    说明
2022-06-15   $22,000    -35%      1      0     模型说买, 但 regime=熊市 → 拦截!
2022-06-18   $17,800    -40%      0      0     BTC 继续下跌 -19%, 躲过一劫

情景 D: 非熊市 + 止盈触发 (完美执行)
日期          价格       63d收益   信号    仓位    说明
2024-08-05   $49,800    -5%       1      1     regime=非熊市 → 执行买入
2024-08-12   $51,900    -3%       0      0     +4.2% ≥ 4% → 止盈, 只持 7 天

情景 E: 熊转牛边缘 (错过机会)
日期          价格       63d收益   信号    仓位    说明
2022-11-21   $16,000    -12%      1      0     63d收益=-12% < -10% → 熊市 → 拦截
2022-12-31   $16,500    -8%       -      -     实际只涨了 3%, 拦截是对的
2023-01-15   $21,000    +5%       1      1     63d收益转正 → 非熊市 → 允许买入 ✔
```

**Regime 开关的代价与收益**:

| 维度 | 无开关 (+止盈) | 有开关 (止盈+regime) | 开关影响 |
|------|-------------|------------------|--------|
| 暴露 | 26.8% | **13.6%** | -49% |
| MaxDD | -24.7% | **-12.7%** | 减半 |
| CAGR | 17.0% | 9.8% | -42% |
| PF | 1.26 | **1.32** | 提升 |
| 2022熊市 | +4.63% | **-0.97%** | 接近零 |
| 2025震荡 | -1.61% | **+11.02%** | 反转! |

> ℹ️ 核心取舍：开关用 CAGR 下降换取回撤减半。适合风险厨恶型资金。

### 三者综合对比

```
                        基础 (激进)       +止盈 (稳健)     止盈+regime (保守)
                       ──────────     ───────────    ───────────────
信号生成:              模型            模型             模型 + regime 过滤
入场:                 y_pred=1         y_pred=1          y_pred=1 且 非熊市
出场:                 T=21 天           min(TP, T=21)     min(TP, T=21, 熊市)
暴露:                 39.4%            26.8%             13.6%
CAGR:                 24.7%            17.0%             9.8%
Sharpe:               0.93             0.77              0.63
MaxDD:                -24.7%           -24.7%            -12.7%
Profit Factor:        1.25             1.26              1.32
适合场景:             小资金/高风险偏好    平衡收益与风险    大资金/风险厨恶
```

**层级关系**:
```
基础 = 模型信号 + 固定 T 天持仓
+止盈 = 基础 + 止盈退出 (TP = X%)
止盈+regime = +止盈 + 熊市空仓 (63d滚动收益率 ≤ -10%)

每层叠加都是策略的「减法」——减少暴露、减少亏损，但也减少了捕捉大行情的机会。
```

### 结论

**✅ 推荐 E1 (不是 E5) 上线，与之前分类指标的推荐相反。**

| 要素 | E1 | E5 |
|------|-----|-----|
| 分类 Kappa | 0.343 | 0.343 |
| 分类推荐 | ⭐ (先前) | ⭐ (后来) |
| **PnL 推荐** | **⭐** | ❌ |
| 原因 | 更严格的阈值产生更高质量信号 | 更宽松的阈值稀释了 alpha |

## 重要警告

1. **买入持有仍然大幅超越所有策略** — 这是 BTC 2022-2026 的牛市偏差，不代表未来
2. **策略低暴露 (39%)** — 大部分时间空仓，剩余资金可其他用途
3. **F1=0 占比仍是 48%** — 分类层面的 fold 稳定性未达标
4. **回测周期仅 3.3 年** — 统计置信度有限，需 paper trading 验证
