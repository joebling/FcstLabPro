执行摘要

  • 对“五维逃顶框架”里 18 个有干净历史数据的指标做了非重叠 Rank IC 检验（样本 2018–2026，方向预先锁定，防未来函数）。
  • Reserve Risk 是唯一统计显著的真 alpha：30d/90d 两窗口均 |t|≥2（-2.14 / -2.65），是 18 因子里唯一达标者。本轮扩充 8 个新因子未能掀翻它，反而强化了其稀缺地位。
  • 新发现：持有人结构是分水岭。长期持有者(LTH)族（LTH-MVRV / LTH-SOPR / LTH-NUPL）方向全对、90d |t|≈1.5–1.75，全部落入 Layer B 确认梯队；短期持有者(STH)族（STH-MVRV / STH-NUPL / STH-SOPR）方向反向、是噪音，不可作逃顶信号。
  • LTH-MVRV (-0.296) 强于现役 Layer B 的 MVRV-Z (-0.261)，建议升为首选确认信号。
  • 情绪/宏观维度（恐贪、资金费率、DXY、美债 10Y）经不起中期检验，部分 90d 反向。
  • 结论有效边界：仅限“可实证的 18 因子子集”。豆包点名的“本轮最关键变量” ETF 资金流、Altseason、交易所净流入 本地无数据、未检验；合约杠杆率本地仅 4 个月数据，样本不足无法测。

1. 研究背景与目标

圈内“五维逃顶框架”（链上估值 / 机构资金 / 宏观流动性 / 技术面 / 衍生品+情绪）与 30 指标实时面板，作为科普清单很全，作为可交易系统有三处结构性缺陷：

缺陷表现后果
无聚合规则各指标只报“完成进度 %”，不说几个命中才动手、权重多少沦为占卜清单，事后挑指标自夸（确认偏误）
绝对阈值刻舟求剑“MVRV-Z 冲 7–10”基于 N=3 历史顶市场结构每轮变，绝对水位系统性下移，阈值失效
慢/快指标混为一谈链上慢变量与情绪快变量平铺并列误判“都没命中=顶还远”，实则慢指标是后视镜

本报告目标：用实测 IC / t-stat 重新给指标定权重、定层级，回答“哪些指标真有 alpha，而非事后叙事”。

2. 方法论

2.1 单资产时序 IC 的诚实声明

本文为单资产 (BTC) 时间序列，无横截面。只能用 signal[t] 对 future_return[t→t+h] 的 Spearman 秩相关：

future_return[t] = price[t+h] / price[t] - 1
RankIC          = spearman( signal[t], future_return[t] )   # 非重叠采样后
t_stat          = IC * sqrt(N-2) / sqrt(1 - IC^2)           # N = 非重叠样本数

2.2 三道防作弊

  1. 非重叠采样：采样步长 = 预测窗口 h（30 或 90 天取一点），避免重叠虚高 t-stat。
  2. 方向锁定：逃顶指标预声明为负 IC（指标越高→未来越跌），不事后反推符号。
  3. 防未来函数：分位用 expanding 扩展窗口，只用 ≤ 当日数据。

2.3 判定门槛

|RankIC| < 0.02 → 噪音放弃 |t| < 1.0 → 不稳定 (Regime 依赖) 1.0 ≤ |t| < 2.0 → 弱有效 |t| ≥ 2.0 → 显著

4. 持有人结构发现 (LTH vs STH)

本轮扩充最有价值的结论：同一估值口径下，长期持有者(LTH)指标是逃顶信号，短期持有者(STH)指标是噪音甚至反向。下图对比 MVRV / NUPL / SOPR 三个口径在 LTH 与 STH 上的 90d RankIC：

LTH 族：真·聪明钱分发信号

LTH-MVRV/SOPR/NUPL 90d 全部负向、|t|≈1.5–1.75，方向锁定全部命中。长期持有者在高位兑现获利，是周期顶部的核心结构特征 → 全部纳入 Layer B 确认。

STH 族：噪音 / 反向，淘汰

STH-NUPL/SOPR/MVRV 30d 全部反向，STH-SOPR 90d 还 +0.18 反向。短期持有者指标反映“近期接盘的散户”，当逃顶信号用方向是反的，不入决策链。

5. 三层精英制框架

实证证伪了“多维等权共振”（等权共振分两窗口都输给单独 Reserve Risk）。正确做法不是民主投票，而是精英制：以最强信号为核心，其余作确认/否决。

层角色用什么为什么
A 主信号定危险等级Reserve Risk expanding 历史分位（连续值）唯一 |t|≥2 的真 alpha；用分位非绝对阈值，防水位漂移
B 确认信号防单信号误报LTH-MVRV（首选） + LTH-SOPR + LTH-NUPL + MVRV-Z + Puell，≥2 高位=确认方向对但 Regime 依赖；LTH 族同源共振，强于散点估值
C 触发择时防接飞刀跌破 SMA50 / 周线 MACD 转负 / 吊灯止损快变量补慢指标滞后；仅在 A/B 已拉警报后启用

相比 v1.1 框架的更新：Layer B 首选确认信号由 MVRV-Z 升级为 LTH-MVRV（90d IC -0.296 > -0.261），并补入 LTH-SOPR。

6. 决策规则 (分批撤退)

危险等级触发条件建议动作
安全Reserve Risk < 历史 70 分位满仓持有
警示RR ∈ [70, 85) 分位停止加仓，关注 Layer C
危险RR ≥ 85 分位 且 Layer B ≥2 高位分批减仓第 1 批（约 30%）
极危RR ≥ 95 分位 且 Layer B ≥3 高位减第 2 批 + Layer C 触发即减第 3 批

为什么分批：慢指标给区间不给点，分批把择时误差摊平。假警报只让你少赚，不让你满仓被埋。全部用 expanding 历史分位、阈值/方向事前锁定。

本位说明（币本位视角）：本框架服务于币本位周期择时——目标是高点减仓、低点接回，最终攒到更多 BTC，而非最大化 USD Sharpe。IC / 超额用 USD 价格收益口径仅为判断信号方向；最终成败以「轮动后 BTC 数量 vs 全程 HODL」衡量（见 §9 路线图 #6）。

8. 局限与覆盖缺口

8.1 统计局限

  1. 样本极少：90 天非重叠采样后 N≈33，即使 Reserve Risk t=2.65，置信区间仍宽。加密只有约 3 轮完整周期。
  2. Regime 依赖：Layer B 全族 |t|<2，意味着“看市场状态吃饭”，下轮未必复现。
  3. 链上数据回填风险 (Layer 0)：回测可能虚高，live 表现打折扣。
  4. 只测线性单调预测力：IC 不捕捉阈值/形态/非线性，不能完全否定人工共振直觉。
  5. 未含交易成本/滑点/延迟：本框架是信号/仓位层；验证靠币本位轮动回测(期末 BTC 数量 vs HODL)，粗算手续费即可，非机构级滑点精度。

8.2 覆盖缺口（对豆包五维清单）

结论有效边界：本报告仅覆盖“有本地数据的 18 因子子集”。对豆包五维的覆盖是部分且不对称的——重叠的仅约 5 个。在补测下列缺口之前，不对豆包的“机构资金维”下结论。

9. 结论与路线图

核心结论

  • 在可实证的 18 因子子集内：Reserve Risk 是唯一显著主信号，扩充实验反向确认其稀缺地位。
  • 持有人结构是分水岭：LTH 族进 Layer B（LTH-MVRV 升为首选确认），STH 族是噪音淘汰。
  • 情绪/宏观维度经不起中期检验；豆包的“机构资金/ETF 维”因无数据尚未检验，结论暂留保留。
  • 本框架是风险管理工具，不是逃顶神器。任何指标都无法 100% 预判顶部。
