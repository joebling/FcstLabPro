执行摘要

  • 本报告是逃顶研究的姊妹篇，回答“能否把逃顶框架对称地拿来抄底”。结论：框架可复用，但 alpha 与动作绝不对称。
  • 方法论陷阱（核心）：单资产全样本 Rank IC 是对称的——翻方向跑底部 = 顶部镜像，|IC|/|t| 一字不差，零新信息。故改用条件分位法：只在 expanding 历史低分位（≤20%，极度低估）子样本上看未来反弹。
  • 冠军换人：顶部唯一硬 alpha 是 Reserve Risk（90d |t|=2.65）；在底部其日频条件分位超额排名退出第一梯队（但事件去重口径下仍可能很强，见 §7，不宜简单判“退位”）。底部更稳的主力是估值类——AVIV / MVRV-Z（低估区 180d 命中 83–87%，超额 +48~53%）；LTH-NUPL / NUPL / LTH-MVRV 更适合作确认层。证伪“底部=顶部反操作”。
  • 底部是长周期游戏：命中率随窗口单调暴涨（30d ≈55–64% → 180d ≈80–87%）；短期抄底（30d）几乎无 edge（超额仅 +0~2%），价值全在 90–180d。
  • “极度恐惧抄底”是伪命题：恐惧贪婪指数低估区 180d 超额 -30.6%（命中仅 48%，跑输基线）。极恐时多在左侧下跌 → 底部必须右侧确认，不做左侧预测。
  • 统计严谨度天然弱于顶部：低估区非重叠采样后 N<8，子样本 IC 做不出显著性——BTC 史上仅 3–4 个大底的结构性限制。底部框架应定位为“长周期参考 + 右侧确认”，而非顶部那种硬 t-stat alpha。
  • 命中率 / 超额是日频重叠计数（违反手册 §2.1 非重叠铁律）：仅用于候选指标排序，不能当独立同分布硬结论。事件去重 sanity check（见 §7）显示 NUPL 日频强但事件口径走弱、Reserve Risk 事件口径仍强——晋升前必须做事件去重 + 右侧触发回测。

1. 研究背景与目标

逃顶报告确立了“三层精英制”顶部框架后，一个自然的对称设想是：既然有“顶部”，能否用同一套 expanding 分位引擎做“底部”，补全项目“有顶、有中间 regime、缺底”的周期择时闭环？本报告用实测数据回答三个问题：

问题朴素假设本报告结论
底部=顶部反操作？把方向翻过来即可否。全样本 IC 对称无新信息；主信号冠军换人
哪些指标真能抄底？沿用 Reserve Risk估值/长持类（MVRV-Z / LTH-NUPL / AVIV）更强
抄底该左侧还是右侧？越恐惧越买右侧。极恐抄底长周期跑输基线

本报告目标：用条件分位命中率 / 超额反弹给底部指标定主次，回答“哪些指标在极度低估区真有反弹预测力，而非全样本线性巧合”。

2. 方法论

2.1 镜像陷阱（为什么不能简单翻方向）

单资产时序的 全样本 Spearman rank IC 是方向对称的：

corr( rank(signal), rank(future_return) )   # 全样本
-> 逃顶检验 (高->跌) 与 抄底检验 (低->涨) 数值完全相同, 仅解释相反
-> 单纯把 direction 从 -1 翻成 +1, |IC|/|t| 一字不差, 零新信息

实证印证（Part A）：MVRV-Z 90d 全样本 IC=-0.261/t=-1.53、Reserve Risk 90d -0.429/t=-2.65，与逃顶报告逐位相同。故全样本 IC 仅作方向基线，底部真信息必须另寻。

2.2 条件分位法 + 三道防作弊

底部的真问题是条件预测力：“当指标处于历史极低分位（极度低估）时，未来是否真反弹？”只在低估子样本上度量：

pct[t]     = expanding 历史分位(signal, <=当日)        # point-in-time
low        = { t : pct[t] <= 20% }                     # 极度低估子样本
命中率      = P( future_return[t->t+h] > 0 | t in low )
超额反弹    = mean(ret | low) - mean(ret | 全样本)       # >0 才有抄底价值
子样本IC    = spearman( signal, ret | low, 非重叠采样 )
  1. 非重叠采样：子样本 IC 每 h 天取一点，避免重叠虚高 t-stat。
  2. 方向锁定：抄底指标预声明为“低分位 → 未来正收益”，不事后反推。
  3. 防未来函数：分位用 expanding 扩展窗口（最少 365 天历史），只用 ≤ 当日数据。

2.3 判定门槛

超额 < 0 → 反向 (避坑) 超额 0–10% → 不显著 超额 ≥ 10% → 弱有效 超额 ≥ 30% 且命中 ≥ 80% → 强 (底部主力) 宏观存疑 (样本偏差)

注：超额 / 命中均以 180d 窗口判定（底部长周期特性）；基线按各指标可用样本期分别计算（主流链上指标约 +33.8%，宏观 DXY/TNX 约 +35.6%，恐惧贪婪 约 +38.4%，资金费率 约 +28.9%）。

3. 条件分位结果 (18 因子)

3.1 低估区 180d 超额反弹排名

超额 = 低估区(分位≤20%)未来 180d 均收益 − 该指标全样本基线(主流链上类≈+33.8%)，越正越强的拄底信号。蓝=强(超额≥30%且命中≥80%)，金=弱有效，灰=不显著，红=反向(失效)，紫=宏观存疑。

注：估值/长持类（AVIV / MVRV-Z / LTH-NUPL）进入蓝色强信号区；STH 族与恐惧贪婪转红(反向)；DXY/TNX 超额最高但为宏观样本偏差(见 §7)。

4. 长周期效应 (命中率随窗口)

底部与顶部最大的不对称：底部是长周期游戏。优质抄底信号的低估区命中率随持有窗口单调爬升至 80%+；反例(恐惧贪婪 / STH-NUPL)反而走平甚至下滑——印证“短期抄底接飞刀，长周期才有 edge”。

纵轴=低估区未来正收益占比；实线=底部主力，虚线=反例。30d 几乎无区分度（都在 55% 附近），180d 拉开到 45% vs 87%。

5. 顶部 vs 底部 (冠军换人)

同一批链上指标，在两端的角色截然不同。顶部硬 alpha Reserve Risk 在底部的日频条件分位排名让位，底部主力换成估值/长持盈亏类——这是“底部 ≠ 顶部反操作”最直接的证据。但注意：Reserve Risk 的“退位”仅限于日频超额排名；按事件去重口径（§7）它仍是最强之一，不可简单判定失效。

6. 底部框架建议 (右侧化)

对称借用顶部的三层结构，但主信号换组、动作右侧化：

层角色用什么 (底部)与顶部的关键差异
A 主信号定机会等级MVRV-Z / AVIV expanding 历史低分位不再是 Reserve Risk；底部估值类更强
B 确认信号防单信号误报LTH-NUPL（首选） + NUPL + LTH-MVRV，≥2 低位=确认仍是长持族，但取“低估”而非“高位”
C 触发择时防接飞刀（右侧）站上 SMA50 / 周线 MACD 转正 / 放量突破权重更高：底部必须右侧确认才建仓
动作：分批建仓（右侧确认）

A 低位 + B≥2 低位 = 进入“机会区”，但等 Layer C 右侧信号才分批建仓，不在左侧下跌中预测抄底。慢指标给区间，右侧给扳机。

为什么比顶部更保守

逃顶错=踏空(仅机会成本)；抄底错=接飞刀(真亏本金)。加上底部样本稀少、统计弱，故宁可右侧追，不可左侧接。

工程落地：把 topping 抽象成双向“周期研判”框架（逃顶 / 抄底双 tab，共享 expanding 分位引擎），避免 DRY 违规，补全周期择时闭环。

7. 局限与红线 (机构手册)

  1. 子样本 IC 不显著：低估区非重叠采样 N<8，t-stat 做不出。BTC 史仅 3–4 大底的结构性限制，非代码缺陷 → 底部框架统计严谨度天然弱于顶部。
  2. 命中率 / 超额为日频重叠计数（违反手册 §2.1 非重叠铁律）：例如 MVRV-Z 的 358 个“低估天”其实只对应 6 段连续低估期，非 358 个独立样本。故该类指标仅能用于候选排序，不能当独立同分布硬结论。事件去重 sanity check（把连续低估日合并为“低估事件段”看首/末日 180d 收益）揭示：AVIV 两口径都强；NUPL 日频强但事件段首日 38.5% 命中/-1.0% 明显走弱（依赖连续低估区内部重叠权重）；Reserve Risk 事件段首日 83.3% 命中/+91.1% 仍强。晋升前必须重跑事件级 + 右侧触发回测。
  3. DXY/TNX 超额最高但存疑：DXY 180d 超额 +87% 极可能是样本偏差 + regime 巧合（大底恰逢美元宽松周期），是宏观流动性因果而非 DXY 预测力。仅作背景旁证，不可当独立 alpha。
  4. 链上数据回填风险 (Layer 0)：回测可能虚高，live 表现打折扣。
  5. 只测线性单调 / 分位预测力：不含成本、滑点、延迟，真实收益需 Layer 5 回测验证。

8. 结论与路线图

核心结论

  • 底部 alpha 有迹象存在，但强度应分层（估值类低估区命中 80%+、180d 超额 +40–53%），但不是顶部镜像——AVIV / MVRV-Z 是更稳的 Layer A 候选；LTH-NUPL / NUPL / LTH-MVRV 更适合作确认层。
  • Reserve Risk 在日频条件分位排名不再第一，但事件去重口径下仍可能很强，不能简单判定退位，需事件级回测进一步验证。
  • 底部是长周期游戏，短期抄底无 edge；极恐抄底是伪命题，必须右侧确认。
  • 统计上比顶部弱（样本稀少），框架应降级为“长周期参考 + 右侧确认”，UI 诚实标注。
  • 本框架是仓位管理工具，不是抄底神器。任何指标都无法 100% 预判底部。
