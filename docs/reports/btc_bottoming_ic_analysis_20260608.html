执行摘要

  • 底部 alpha 真实存在,但冠军换人:顶部唯一硬 alpha 是 Reserve Risk(|t|=2.65);底部退位到中游,真冠军是估值/长持盈亏类 —— AVIV / MVRV-Z / NUPL / LTH-NUPL(低估区 180d 命中率 79–87%,超额 +41~53%)。证伪"底部=顶部反操作"。
  • 底部是长周期游戏:命中率随窗口单调暴涨(30d ≈55–64% → 180d ≈80–87%)。短期抄底(30d)几乎无 edge(超额仅 +0~2%),价值全在 90–180d。
  • "极度恐惧抄底"是伪命题:恐惧贪婪指数低估区 180d 超额 -30.6%(命中仅 48%,跑输基线)。极恐时多在左侧下跌 —— 底部必须右侧确认,不做左侧预测。
  • 短持(STH)系列全线反向(超额全负),与顶部研究一致,两端皆可剔除。
  • 统计严谨度天然弱于顶部:低估区非重叠采样后 N<8,子样本 IC 做不出显著性 —— BTC 史上仅 3–4 个大底的结构性限制。底部框架应定位为"长周期参考 + 右侧确认",而非顶部那种硬 t-stat alpha。

1. 方法论 (两段式)

陷阱:全样本 IC 镜像

单资产全样本 Spearman rank IC 是对称的:corr(rank(信号),rank(未来收益)) 数值与逃顶检验完全相同,仅方向解释相反。单纯翻方向 = 顶部镜像,零新信息。本报告 Part A 仅作方向基线已弃。

底部特异:条件分位 IC

真问题是"指标处于 expanding 历史低分位(≤20%,极度低估)时,未来是否真反弹?"只在低估子样本上看命中率 / 超额反弹 / 子样本 IC。point-in-time 防未来函数,方向预声明(低→涨),不事后反推。

2. 低估区 180d 超额反弹排序

超额 = 低估区(分位≤20%)未来 180d 均收益 − 全样本基线(+33.8%)。>0 才有抄底价值。蓝=链上估值/长持 · 绿=矿工/其他链上 · 紫=宏观(存疑) · 红=反向(避坑)

3. 命中率随持有窗口 (长周期效应)

代表指标低估区"未来正收益占比"在 30 / 90 / 180 天的变化。优质抄底信号单调爬升至 80%+;反例(恐惧贪婪/STH-NUPL)反而走平或下滑。

5. 局限与红线 (机构手册)

  • 子样本 IC 不显著:低估区非重叠采样 N<8,t-stat 做不出。BTC 史仅 3–4 大底的结构性限制,非代码缺陷。
  • 命中率/超额为日频重叠计数:看趋势可以,不能当独立同分布样本下硬结论。
  • DXY/TNX 超额最高但存疑:DXY 180d 超额 +87% 极可能是样本偏差 + regime 巧合(大底恰逢美元宽松周期),是宏观流动性因果而非 DXY 预测力。最多作背景旁证,不可当独立 alpha。
  • Layer 0 风险:链上数据可能被数据源回填修正,真实 live 表现或低于此回测。

6. 结论与落地建议

值得做,但定位要诚实。底部 alpha 真实(估值类低估区命中 80%+、180d 超额 +40–53%),方向逻辑清晰,但:

① 主信号换组:Layer A/B 用本次实证的 MVRV-Z / LTH-NUPL / AVIV(估值/长持),而非照抄顶部的 Reserve Risk。

② 动作右侧化:抄底默认"右侧确认建仓"(Layer C 站上 SMA50 / 周线 MACD 转正 + 放量),不做左侧预测,因抄底错=接飞刀(真亏本金) vs 逃顶错=踏空(仅机会成本)。

③ UI 诚实标注:"长周期参考(90–180d)、样本稀少、需右侧确认",降级展示,不与顶部硬 alpha 混淆。

④ 工程落地:将 topping 抽象为双向"周期研判"框架(逃顶/抄底双 tab,共享 expanding 分位引擎),避免 DRY 违规;补全项目目前"有顶、有中间 regime、缺底"的择时闭环。
