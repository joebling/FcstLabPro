执行摘要

V2 校准 (2026-06-09)：本报告初版 headline 用日频重叠命中率/超额，被 review 指出夸大。本版改用事件级(非重叠，每个低估段取首日)主口径 + 统一基线重算，结论大幅放软并部分反转。日频口径降级为「仅排序参考」。本框架服务币本位周期择时，非机构 alpha。

  • 本报告是逃顶研究的姊妹篇，回答「能否把逃顶框架对称地拿来抄底」。结论：框架可复用，但底部 alpha 远比初版以为的弱。
  • 方法论陷阱（核心）：单资产全样本 Rank IC 是对称的——翻方向跑底部 = 顶部镜像，零新信息。故改用条件分位法：只在 expanding 历史低分位（≤20%，极度低估）子样本上看未来反弹。
  • 「87% 命中神器」是重叠幻觉。事件级一去重，初版冠军全部缩水甚至翻负：AVIV 180d 超额 +52.6%→+10.5%(N=3)、MVRV-Z +46.9%→+6.6%、LTH-NUPL +40.4%→−35.7%、NUPL +40.4%→−19.3%（直接翻负）。它们的高分纯粹是「6 个周期故事讲了 358 遍」。
  • 左侧首日抄底基本全军覆没（但这是好消息）。「低估段首日」通常仍在下跌途中=接飞刀，故事件级 180d 超额多为负。这用硬数据证实了「必须右侧确认、不做左侧预测」——抄底框架的灵魂不在选指标，在右侧扳机。
  • 事件级仅存的微弱正超额（180d，vs 统一基线 +34.5%）：Reserve Risk +12.4%(命中75%/N=4)、AVIV +10.5%、MVRV-Z +6.6%。注意：Reserve Risk 事件级反而最稳，初版「Reserve Risk 在底部退位」的说法被反转。
  • 统计天然弱，样本是宿命：事件去重后每指标仅 3–6 个独立周期，子样本 IC 几乎全 n/a。BTC 史上仅 3–4 个大底——底部框架只能定位为「长周期机会区间排序 + 右侧确认」，绝非 t-stat 硬 alpha。
  • 本位说明：超额/命中是 USD 价格收益口径（仅用于判方向 + 给指标排座次）。「照这套轮动能不能攒到更多 BTC」需币本位轮动回测（路线图 #5）单独验证。

1. 研究背景与目标

逃顶报告确立了“三层精英制”顶部框架后，一个自然的对称设想是：既然有“顶部”，能否用同一套 expanding 分位引擎做“底部”，补全项目“有顶、有中间 regime、缺底”的周期择时闭环？本报告用实测数据回答三个问题：

问题朴素假设本报告结论
底部=顶部反操作？把方向翻过来即可否。全样本 IC 对称无新信息；且事件级 alpha 远弱于顶部
哪些指标真能抄底？沿用 Reserve Risk事件级仅 RR / AVIV / MVRV-Z 微弱正超额（+6~12%），其余多翻负
抄底该左侧还是右侧？越恐惧越买右侧。左侧首日进场事件级超额多为负（接飞刀）

本报告目标：用条件分位命中率 / 超额反弹给底部指标排序定主次，诚实回答“哪些指标在极度低估区真有反弹预测力、能否经住事件去重”。不追求统计显著（样本不够），只求周期逻辑 + 右侧确认。

2. 方法论

2.1 镜像陷阱（为什么不能简单翻方向）

单资产时序的 全样本 Spearman rank IC 是方向对称的：

corr( rank(signal), rank(future_return) )   # 全样本
-> 逃顶检验 (高->跌) 与 抄底检验 (低->涨) 数值完全相同, 仅解释相反
-> 单纯把 direction 从 -1 翻成 +1, |IC|/|t| 一字不差, 零新信息

实证印证（Part A）：MVRV-Z 90d 全样本 IC=-0.261/t=-1.53、Reserve Risk 90d -0.429/t=-2.65，与逃顶报告逐位相同。故全样本 IC 仅作方向基线，底部真信息必须另寻。

2.2 条件分位法 + 三道防作弊

底部的真问题是条件预测力：“当指标处于历史极低分位（极度低估）时，未来是否真反弹？”只在低估子样本上度量：

pct[t]      = expanding 历史分位(signal, <=当日)        # point-in-time
low         = { t : pct[t] <= 20% }                     # 极度低估子样本
【主口径·事件级】 把连续低估日塌缩成事件段(间隔>h=新段), 取每段首日
事件命中   = P( future_return > 0 | 低估段首日 )           # N 诚实=周期数(~3-6)
事件超额   = mean(ret | 低估段首日) - 统一基线
【仅排序·日频】 重叠计数(6个故事讲358遍), 命中率系统性夸大, 不当硬结论
统一基线   = mean(ret) over [2018-02, 2025-12]          # 全指标共用, 价格口径
  1. 事件级去重（主口径）：连续低估日塌缩成独立事件段，取首日，N 诚实反映周期数。防重叠虚高。
  2. 统一基线：所有指标减同一个价格口径基线（2018-02~2025-12），超额才可横向比。
  3. 方向锁定：抄底指标预声明为“低分位 → 未来正收益”，不事后反推。
  4. 防未来函数：分位用 expanding 扩展窗口（最少 365 天历史），只用 ≤ 当日数据。

2.3 判定门槛（事件级）

事件超额 < 0 → 左侧失效 (接飞刀) 事件超额 ≈0 / 命中<60% → 不显著 事件超额 >0 且 命中≥60% 且 N≥3 → 微弱正 edge 宏观/情绪存疑 (N≤3 或口径矛盾)

注：主口径为事件级（低估段首日、非重叠）；日频重叠仅供排序。超额 / 命中以 180d 窗口判定（底部长周期特性）；基线改为统一价格口径（2018-02~2025-12，剖资金费率交集）：30d≈+4.3% / 90d≈+14.9% / 180d≈+34.5%。修正初版「按各指标可用样本期分别计算」的苹果比橘问题。

4. 长周期效应 (命中率随窗口)

警示：本图用日频(重叠)命中率，仅供趋势观察。“命中率随窗口爬升至 80%+”部分是重叠伪象（越长窗口越多重叠日集中在同一周期底。事件级首日口径下 180d 命中多仅 33~67%）。但“短期抄底(30d)无 edge”这个定性结论仍成立。

底部与顶部最大的不对称：底部是长周期游戏。优质抄底信号的低估区日频命中率随持有窗口抬升；反例(恐惧贪婪 / STH-NUPL)反而走平甚至下滑——印证“短期抄底接飞刀，长周期才有 edge”。

纵轴=低估区未来正收益占比（日频重叠口径·仅趋势）；实线=初版主力，虚线=反例。注意：这里 180d“拉开到 87%”是重叠伪象，事件级首日口径下该值跌至 33~67%（见 §3 / §5）。但 30d 无区分度这个定性结论可靠。

5. 顶部 vs 底部 (冠军换人)

同一批链上指标，在两端的角色截然不同。但事件级口径下出现了关键反转：初版说“Reserve Risk 在底部退位、估值类上位”，但那是日频重叠排名的幻觉。事件级下 Reserve Risk 反而是底部唯一相对稳的信号（+12.4%/命中75%/N=4）；LTH-NUPL/NUPL 的“初版冠军”身份翻负（日频 +40% 是重叠伪象，事件级首日接飞刀 −19~−36%）。“底部 ≠ 顶部反操作”仍成立，但方向与初版相反。

6. 底部框架建议 (右侧化)

对称借用顶部的三层结构，但主信号换组、动作右侧化：

层角色用什么 (底部)与顶部的关键差异
A 主信号定机会区间Reserve Risk(事件级最稳) + AVIV / MVRV-Z expanding 历史低分位事件级下 RR 仍最稳（初版误判其退位）；但仅微弱 edge
B 确认信号防单信号误报AVIV + MVRV-Z 互验，≥2 低位=确认（慎用 LTH-NUPL/NUPL：左侧首日翻负）不再把 LTH-NUPL 当首选；事件级它接飞刀
C 触发择时防接飞刀（右侧）站上 SMA50 / 周线 MACD 转正 / 放量突破权重最高：事件级已证明左侧入场全废，右侧是刚需
动作：分批建仓（右侧确认）

A 低位 + B≥2 低位 = 进入“机会区”，但等 Layer C 右侧信号才分批建仓，不在左侧下跌中预测抄底。慢指标给区间，右侧给扳机。

为什么比顶部更保守

逃顶错=踏空(仅机会成本)；抄底错=接飞刀(真亏本金)。加上底部样本稀少、统计弱，故宁可右侧追，不可左侧接。

工程落地：把 topping 抽象成双向“周期研判”框架（逃顶 / 拄底双 tab，共享 expanding 分位引擎），避免 DRY 违规，补全周期择时闭环。

本位说明（币本位视角）：本框架服务于币本位周期择时——目标是低点用稳定币接回 BTC、高点减仓，最终攒到更多 BTC，而非最大化 USD Sharpe。命中率 / 超额用 USD 价格收益口径仅为判断信号方向 + 给指标排座次；最终成败以「轮动后 BTC 数量 vs 全程 HODL」衡量（见 §8 路线图 #5）。

7. 局限与红线 (机构手册)

  1. 事件级是主口径，日频重叠仅排序（本版已收口）：MVRV-Z 的 358 个“低估天”其实只对应 ~3–6 段独立低估期。初版 headline 用日频重叠（87% 命中）被证伪。事件级一去重：左侧首日进场大部分指标 180d 超额转负（LTH-NUPL −35.7%、NUPL −19.3%）；仅 Reserve Risk / AVIV / MVRV-Z 微弱正（+6~12%）。这是「必须右侧确认」的硬证据。
  2. 子样本 IC 不显著：事件去重后每指标仅 N=2~6，t-stat 几乎全 n/a。BTC 史仅 3–4 大底的结构性宿命，非代码缺陷 → 底部框架统计严谨度天然弱于顶部，只能做排序不能做显著性。
  3. DXY/TNX 超额最高但存疑：DXY 180d 超额 +87% 极可能是样本偏差 + regime 巧合（大底恰逢美元宽松周期），是宏观流动性因果而非 DXY 预测力。仅作背景旁证，不可当独立 alpha。
  4. 链上数据回填风险 (Layer 0)：回测可能虚高，live 表现打折扣。
  5. 只测线性单调 / 分位预测力：不含成本、滑点、延迟；验证靠币本位轮动回测(期末 BTC 数量 vs HODL)，粗算手续费即可，非机构级滑点精度。

8. 结论与路线图

核心结论

  • 事件级一去重，底部 alpha 远比初版弱：仅 Reserve Risk / AVIV / MVRV-Z 有微弱正超额（180d +6~12%，vs 基线+34.5%）；初版“87% 命中冠军”LTH-NUPL/NUPL 事件级翻负。
  • 初版说法被反转：Reserve Risk 事件级反而是底部最稳的信号（非退位）；估值类 AVIV/MVRV-Z 仅微弱领先。
  • 左侧首日抄底被证伪：这用硬数据印证“底部是长周期游戏 + 必须右侧确认”；短期抄底无 edge，极恐抄底伪命题。
  • 统计上比顶部弱很多（事件 N=2~6），框架只能定位为“长周期机会区间排序 + 右侧确认”，UI 诚实标注。
  • 本框架是币本位仓位管理工具，不是抄底神器。任何指标都无法 100% 预判底部；能不能攒更多币需路线图 #5 币本位轮动回测验证。
