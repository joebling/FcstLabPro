## 0. 术语与数据源

### 0.1 术语表

| 术语 | 含义 |
|------|------|
| **Reserve Risk (储备风险)** | 价格 / (长期持币者机会成本 HODL Bank), 衡量“长期持币者信心 vs 当前价格”。低=信心高价格低(低风险), 高=价格透支信心(高风险)。 |
| **MVRV-Z** | (市值 − 已实现市值) / 市值标准差, 衡量全市场浮盈偏离程度。 |
| **NUPL** | 净未实现盈亏, 全市场账面浮盈占市值比例。 |
| **LTH-NUPL** | 仅长期持币者 (持币>155天) 的 NUPL。 |
| **Puell 倍数** | 矿工日收入 / 365日平均收入, 衡量矿工抛压。 |
| **Rank IC** | Spearman 秩相关系数, signal[t] vs future_return[t→t+h]。 |
| **t-stat** | IC 的统计显著性, |t|≥2 约当 95% 置信。 |
| **expanding 历史分位** | 只用 ≤ 当日数据计算“当前值在历史中的百分位”, 严格无未来函数。 |
| **分批撤退** | 分多次减仓而非一次清仓, 把择时误差摊平。 |

## 2. 方法论 (IC / t-stat / 分位 定义)

### 2.1 单资产时序 IC 的诚实声明

本文是**单资产 (BTC) 时间序列**, 无横截面。手册 §2.3 “IC t-stat 基于 IC 时间序列”
针对的是**多资产截面 alpha**。单资产只能用 signal[t] vs future_return[t→t+h] 的 Spearman:

```
future_return[t] = price[t+h] / price[t] - 1
RankIC          = spearman( signal[t], future_return[t] )   # 非重叠采样后
t_stat          = IC * sqrt(N-2) / sqrt(1 - IC²)            # N = 非重叠样本数
```

### 2.2 三道防作弊 (手册 §2)

1. **非重叠采样 (§2.1)**: 采样步长 = 预测窗口 h (30 或 90 天取一点), 避免重叠虚高 t-stat。
   *这正是本项目 regime 研究里踩过的坑 (单日滞动 → 同一日期被数 ~2.89 次)。*
2. **方向锁定 (§2.2)**: 逃顶指标预声明为**负 IC** (指标越高→未来越跌), 不事后反推符号。
3. **防未来函数 (Layer 0)**: 分位用 expanding 扩展窗口, 只用 ≤ 当日数据。

### 2.3 判定门槛 (手册 §3.3)

| 指标 | 门槛 | 含义 |
|------|------|------|
| \|Rank IC\| | > 0.02 | 低于此=噪音, 放弃 |
| \|t-stat\| | ≥ 1.0 初筛 / ≥ 2.0 显著 | 低于 1.0 = 不稳定(Regime 依赖) |

## 3. 实证基础: 哪些指标真有 alpha (t-stat 而非故事)

### 3.1 单因子 IC 检验 (脚本 `topping_indicator_ic.py`)

非重叠采样 (步长=预测窗口, 手册 §2.1), 方向预先锁定 (手册 §2.2), 样本 2018~2026:

| 指标 | 30d RankIC / t | 90d RankIC / t | 判定 |
|------|---------------|----------------|------|
| **Reserve Risk** | **-0.21 / -2.14** ✅ | **-0.43 / -2.65** ✅ | 🥇 唯一两窗口 t≥2 |
| LTH-NUPL | -0.12 / -1.20 | -0.27 / -1.56 | 🥈 Regime 依赖 |
| MVRV-Z | -0.10 / -1.03 | -0.26 / -1.53 | 🥈 Regime 依赖 |
| Puell 倍数 | -0.04 / -0.41 | -0.28 / -1.63 | 🥈 仅 90d 有戏 |
| NUPL | -0.08 / -0.82 | -0.25 / -1.46 | 🥈 Regime 依赖 |
| 资金费率 | -0.14 / -1.23 | +0.02 / 噪音 | 🥉 仅短线情绪 |
| 恐惧贪婪指数 | +0.05 / 反向 | -0.03 / 噪音 | ❌ 中期无效 |
| DXY 美元指数 | -0.01 / 噪音 | +0.23 / 反向 | ❌ 单资产近乎全废 |
| 美债 10 年 | -0.11 / -0.87 | +0.05 / 反向 | ❌ 不稳定 |

**关键发现**:
1. **Reserve Risk 是隐藏冠军** — 豆包框架/30 指标面板都没单列, 却是唯一统计显著的真 alpha。
2. **链上估值四件套 (MVRV-Z/NUPL/LTH-NUPL/Puell)** 方向全对但 **|t|<2 = Regime 依赖** — 印证用户"经历几轮周期感觉挺对"的体感: 它们**在历史那几个顶确实亮了, 但样本太少 (N≈33), 不保证下轮必灵**。
3. **情绪/宏观维度 (恐贪、资金费率、DXY、美债) 经不起中期检验** — 氛围组, 非预测器。豆包框架把宏观列为"关键维度"是**高估了**。
4. **链上指标全是慢变量**: 30d 普遍不显著, 90d 才有意义 → **给不了日期, 只给"危险区间"**。

### 3.2 "等权共振"证伪 (脚本 `topping_resonance_ic.py`)

把 5 个链上指标做成 expanding 历史分位 (point-in-time 防未来函数) 的 0~5 共振分:

| 信号 | 30d \|t\| | 90d \|t\| |
|------|----------|----------|
| ★ 等权共振分 (0~5) | 0.98 | 1.04 |
| 单独 Reserve Risk | **2.26** | **2.69** |

**等权共振分两窗口都输给单独 Reserve Risk。** 原因:
- **二值化丢信息** (95 分位与 81 分位都压成 1)。
- **等权 = 学渣拉低学霸** (t=2.7 的 Reserve Risk 被 t=1.3 的 Puell 稀释)。
- **指标高度共线** (MVRV/NUPL/LTH-NUPL 都量"未实现盈利", 重复计数同一信息)。

>  **结论**: "多维平权共振"是漂亮的失败实验。正确做法不是民主投票, 而是 **精英制**: 以最强信号为核心, 其余作确认/否决。(与本项目 regime 研究 §2.1 多维 regime 证伪同一教训: 直觉化的"更专业" ≠ 更赚钱。)

## 4. 框架设计: 三层精英制 (替代等权清单)

### 4.1 核心理念

> 顶部研判目标 = **不在山顶接最后一棒, 活着撤退** (风险预算管理),
> 而非**精准卖在最高点** (后者是不可能任务, 慢指标天然滞后)。
> 容忍"早撤 1~2 个月", 不容忍"满仓被埋"。**分批撤退**是处理"知道危险、不知哪天"的最优解。

### 4.2 三层结构

```
Layer A 主信号 (定"危险等级")  —— 唯一统计显著, 权重最高
   └─ Reserve Risk 的 expanding 历史分位 (连续值, 非二值)

Layer B 确认信号 (是否"共识危险")  —— Regime 依赖, 只做二次确认/加码
   └─ MVRV-Z + LTH-NUPL + Puell 的历史分位 (≥2 个同时高位 = 确认)

Layer C 触发/择时 (何时"动手撤")  —— 短周期, 只在 A/B 已拉警报后启用
   └─ 跌破 SMA50 / 周线 MACD 转负 / 吊灯止损 (注: 纯择时, 不判周期方向)
```

### 4.3 三层分工说明

| 层 | 角色 | 用什么 | 为什么 | 不用什么 |
|----|------|--------|--------|----------|
| **A 主信号** | 定危险等级 | Reserve Risk expanding 分位 (连续) | 唯一 t≥2 的真 alpha | 别用绝对阈值 (会漂移) |
| **B 确认信号** | 防单信号误报 | MVRV-Z/LTH-NUPL/Puell 分位, ≥2 高位 | 他们 Regime 依赖但方向对 | 别等权求和 (被证伪) |
| **C 触发择时** | 防接飞刀 | SMA50/MACD/吊灯止损 | 快变量, 补慢指标的滞后 | 别单独用 (假信号多) |

**豆包五维框架的重新定位** (五维逐一对应, 不漏维):
- “链上估值” (五维之一) → 拆成 Layer A (Reserve Risk) + Layer B (其余), 不再平铺。
- “机构资金 / ETF 流” (五维之一) → **暂缺位**: 本文尚未取得 ETF 流数据, 无法 IC 检验, 故未纳入决策链。这是已知**最大缺口** (见 §3.3), 待补测后再定层级——**在此之前不对该维度下结论**。
- “技术面” (五维之一) → 降为 Layer C 择时工具, 不单独决策。
- “衍生品杠杆 + 情绪” (五维之一) → 降为“氛围参考”, **不入决策链** (实测中期 IC 反向/噪音)。
- “宏观流动性” (五维之一) → **降权至背景**, 单资产线性检验近乎全废 (但可作定性风险提示)。

> 说明: 早期草稿曾把“衍生品+情绪”误记为“五维之二”而漏掉“机构资金”维, 导致名义五维、实质只重定位四维。现已修正——机构资金维**没有被降权, 而是尚未检验**, 二者性质不同。

## 5. 具体决策规则 (分批撤退)

### 5.1 危险分级 (基于 Layer A + B, point-in-time)

| 危险等级 | 触发条件 | 建议动作 |
|---------|---------|---------|
| 🟢 安全 | Reserve Risk < 历史 70 分位 | 满仓持有 |
| 🟡 警示 | RR ∈ [70, 85) 分位 | 停止加仓, 开始关注 Layer C |
| 🟠 危险 | RR ≥ 85 分位 **且** Layer B ≥2 个高位 | 分批减仓第 1 批 (如30%) |
| 🔴 极危 | RR ≥ 95 分位 **且** Layer B ≥3 个高位 | 减仓第 2 批 + Layer C 任一触发即减第 3 批 |

> **为什么分批**: 慢指标给区间不给点, 分批把择时误差摊平。假警报只让你少赚, 不让你亏。

### 5.2 关键约束 (防自欺欺人)

1. **全部用 expanding 历史分位, 不用绝对阈值** — 避免“MVRV 要到 7”这种刻舟求剑 (每轮水位下移)。
2. **阈值/方向事前锁定, 不事后调** — 手册 §2.2 锁定原则, 进入观察后不反推。
3. **Layer C 不单独触发减仓** — 必须 A/B 已拉警报, 否则牛市中途洗盘会把你拖下车。
4. **链上数据有回填风险 (Layer 0)** — live 表现可能低于回测, 留安全边距。

### 5.3 与生产模型 (e20c) 的关系

本框架是 **仓位/风险层 (Layer 4 思路)**, 与 e20c (信号层) 正交: 
- e20c 管“何时超卖反弹入场”, 本框架管“周期顶部该不该降总仓位”。
- 可作为现有 regime 开关的**互补** (regime 管深熊静默, 本框架管顶部减仓), 对应 regime 研究 §6 遗留 TODO。

## 7. 局限性与风险声明

诚实拆稿, 避免自欺欺人 (手册 §4.2):

1. **样本极少**: 90 天非重叠采样后 N≈33, 即使 Reserve Risk 的 t=2.69, 置信区间仍宽。
   加密只有 ~3 轮完整周期, **任何“历史规律”都是小样本推断**。
2. **Regime 依赖**: Layer B 四件套 |t|<2, 意味着它们“看市场状态吃饭”, 下轮未必复现。
3. **链上数据回填 (Layer 0)**: 回测可能虚高, live 表现打折扣。
4. **只测线性单调预测力**: IC 不捕捉阈值/形态/非线性, 不能完全否定人工“共振”直觉。
5. **未含交易成本/滞滞**: 本框架是信号/仓位层, 真实收益需 Layer 5 回测验证 (见路线图)。
6. **不是逃顶神器**: 慢指标天然滞后, 本框架目标是“不接最后一棒”而非“卖在最高点”。
   要及时逃顶需趋势跟随/动量背离等更短周期工具 (见 regime 研究 §3.5)。
7. **覆盖不全 (见 §3.3)**: 只验证了豆包五维中**有本地数据的 9 个子集**。尤其**机构资金维 (ETF 流)、Altseason、交易所净流入均未检验**——而 ETF 流是豆包点名的「本轮最关键变量」。本文对豆包「高估宏观/情绪」的评判仅限于可实证子集, 资金面快变量待补测后才能定论。

## 9. 一句话总结

在**可实证的 9 指标子集内**: 豆包五维框架是**对的方向、待校准的权重**——宏观/情绪维经不起中期检验, 而真冠军 Reserve Risk 被漏掉。
**但留一个明确保留**: 豆包点名的「最关键变量 ETF 资金流」 (机构资金维) 本文尚未检验, 故不能对该维下结论 (见 §3.3 / §7.7)。
30 指标面板数据是真的, 但“平铺 + 完成进度%”的用法会误导。
**目前可用的是: Reserve Risk 主信号 (连续历史分位) + 2~3 个链上估值确认 + 技术面择时, 驱动分批撤退; ETF 流/Altseason 等资金面快变量待补测。**

> ⚠️ 本框架是风险管理工具, 不是逃顶神器。任何指标都无法 100% 预判顶部 — 这是共识, 不是缺陷。
