# 20260605 — BTC 四年周期研究: 节奏重复 & 振幅衰减

> **类型**: 研究备忘录 (宏观视角)

> **触发**: regime 开关滞后性研究(§3.5)引出"什么工具能逃顶"→"四年周期是否可靠"
> **核心观点**: 节奏(时间)大概率重复, 幅度(涨跌)持续衰减 — 阻尼振荡模型

## 1. 数据验证: 三项核心指标

### 1.1 顶到顶 / 底到底 间隔

| 类型 | 区间 | 天数 | 年 |
|------|------|------|-----|
| 顶→顶 | 2017→2021 | 1422 | **3.90** |
| 顶→顶 | 2021→2025 | 1428 | **3.91** |
| 底→底 | 2018→2022 | 1437 | **3.94** |

三个独立间隔全部落在 **3.90-3.94 年**, 误差 < 2 周。
在金融时间序列里这种一致性相当罕见 — **节奏极稳**。

### 1.2 减半 → 顶部 (周期论核心因果)

| 区间 | 天数 | 月数 |
|------|------|------|
| 2016减半 → 2017顶 | 526 | **17.5** |
| 2020减半 → 2021顶 | 546 | **18.2** |
| 2024减半 → 2025顶 | 534 | **17.8** |

三轮均在减半后 **17.5-18.2 个月**见顶, 窗口极窄。

### 1.3 底→顶 涨幅倍数 (振幅衰减 — 核心发现)

| 周期 | 底价 | 顶价 | 涨幅 | 是上轮的 |
|------|------|------|------|---------|
| 周期1 (2015-2018) | $152 | $19,783 | **130x** | — |
| 周期2 (2018-2022) | $3,212 | $67,526 | **21x** | 16% |
| 周期3 (2022-2025) | $15,781 | $124,659 | **7.9x** | 38% |

**130x → 21x → 7.9x**: 典型阻尼振荡。每轮涨幅断崖式衰减。

### 1.4 顶→底 回撤深度 (熊市也在变浅)

| 周期 | 回撤 |
|------|------|
| 周期1顶→底 | -84% |
| 周期2顶→底 | -77% |
| 周期3顶→底 | 进行中 |

牛市涨幅衰减, 熊市深度也在收敛。市场双向都在"成熟"。

## 2. 核心观点: 阻尼振荡模型

**普通四年周期论**: 历史重复。
**本研究观点(数据支持)**: 节奏重复, 但振幅持续衰减。

```
振幅
 ^
 |  *                      ← 周期1 (130x)
 |
 |        *                ← 周期2 (21x)
 |
 |              *          ← 周期3 (7.9x)
 |
 |                    ?    ← 周期4 (?)
 +--+--------+--------+---> 时间(年)
   2017      2021     2025
```

类比物理中的**阻尼钟摆**: 摆动周期(时间)稳定, 但每次摆幅因摩擦(市场成熟)越来越小。

### 为什么振幅必然衰减? (因果支撑)

1. **市值基数变大**: $30B → $2.5T, 再翻130倍需要全球GDP量级资金
2. **机构化 + ETF**: 大资金平滑极端波动, 削平暴涨暴跌
3. **减半边际影响趋零**: 新增供给占总流通比例越来越小
4. **边际买家枯竭**: 每轮新参与者增量递减

这些都是**单向、不可逆**的结构性变化, 衰减有方向性。

## 3. 统计 Caveat (保持清醒)

| 问题 | 说明 |
|------|------|
| **N=3** | 根本性硬伤。3个点无法排除巧合, 统计上不能证伪"偶然" |
| **衰减率不稳定** | 16% → 38%, 衰减率本身也在变, 无法精确预测下轮涨幅 |
| **范式转移风险** | ETF/国家储备/监管变化, 任意一轮可能打破节奏 |
| **幸存者偏差** | 知道顶在哪后才回去量间隔, 事后叙事 |

## 4. 与 regime 开关研究的关系 (同一条研究主线)

本研究是从"regime 开关滞后性实证"(§3.5, `20260605_e20c_regime_applicability.md`)
自然延伸出来的:

```
regime开关逃不了顶 (滞后37天, 距顶-18.5%)
    ↓
逃顶工具全军覆没 (所有工具触发后BTC平均仍涨)
    ↓
根本矛盾: 灵敏度 vs 准确率, 逃顶是伪命题
    ↓
四年周期: 给"季节感"(先验), 但不是精确时钟
    ↓
真正的解: 仓位管理 + 波动率目标 (手册 §4.1)
```

## 5. 实用建议

| 建议 | 说明 |
|------|------|
| 把周期当**贝叶斯先验** | 提供"季节感", 不当精确交易信号 |
| 减半后 12-18 个月**提高警戒** | 三轮验证, 先验概率高 |
| **动态调仓**而非二元进出 | 结合实时波动率, 涨多了主动减仓 |
| 每轮**预期收益打折** | 7.9x 之后, 下轮可能更低; 别用历史涨幅外推 |
| 关注**底部确认** | 周期3顶→底尚未完成, -77%还是-60%? 持续观察 |

## 6. 周期4 展望 (基于历史规律外推, 仅供参考)

> ⚠️ 以下为机械外推, 不构成投资建议, N=3 置信度极低。

若节奏重复:
- **预计周期4顶**: 2025-10-06 + 3.91年 ≈ **2029年9月**
- **预计减半→顶**: 2028年4月减半 + 18个月 ≈ **2029年10月** (与上吻合)
- **预计涨幅**: 若衰减率继续约38%, 则 7.9x × 38% ≈ **3x** (底→顶)
- **周期3底部**: 若回撤收窄至 -70%, 则约 **$37,000** (届时底部)

这些数字唯一的用途是"感受量级", 不是预测。
