## 🎯 TL;DR (一句话)

## 🔑 核心认知: 水位 vs 动量

Phase 3 最大的收获不是某个策略, 而是**搞清了链上指标"怎么用才对"**:

| | 水位 (level) | 动量 (momentum) |
|---|---|---|
| 含义 | 指标到了高/低位 | 指标方向在变 |
| Case A | — | 信号B(动量转负)有效 ✅ |
| Case B | 逆向(1-rank) Sharpe 0.44 ❌ | MVRV动量 Sharpe 0.94 ✅ |
| Case C | 极值分位全反向 ❌ | — |
| 结论 | **在钝化+长牛市场失效** | **能抓趋势拐点** |

**为什么水位失效**: BTC 处于结构性长牛 + 周期钝化 (MVRV-Z 顶部峰值逐轮下降:
2017=10 → 2025=3.05)。绝对/分位水位"高了还能更高, 低了还能更低", 没有均值回归锚点。

**为什么动量有效**: 趋势市场里"方向"本身就是信号。MVRV-Z 动量 = 链上资金的趋势确认。

## 📈 Case B 详情 (唯一上得了台面的产出)

月度再平衡, 成本 0.2%/边, 101 个月 (2018-01~2026-06):

| 策略 | Sharpe | MaxDD | CAGR | Total |
|---|---|---|---|---|
| BuyHold | 0.67 | -73% | 26% | 615% |
| 固定半仓 | 0.67 | -45% | 18% | 311% |
| 逆向(1-rank 水位) | 0.44 | -60% | 9% | 114% ❌ |
| **MVRV-Z 动量(3M>0)** | **0.94** | -42% | **43%** | **1888%** ✅ |
| 价格趋势(3M>0) | 0.81 | -50% | 34% | 1100% |

**稳健性 (诚实): ⚠️ 单点敏感, 不是 plateau**。动量窗口 2/3/4/6月 =
0.77/0.94/0.87/0.69, 3月单点最优, 6月骤降到 0.69 (跨度 0.25)。
**别把 3月当甜蜜点调优** — 与 Case A hold=63 同类警示。

**指标横向** (同 3M 动量逻辑): Puell 1.03 > MVRV-Z 0.94 > SOPR 0.71。
三个链上动量都 ≥ 价格趋势(0.81), 但 Puell 反超 MVRV-Z → "哪个指标最优"也不稳。

**关键正面证据**: MVRV-Z 动量(0.94) **胜纯价格趋势(0.81)** — Phase 3 首次看到
链上指标**赢过纯价格**。但增量仅 0.13 Sharpe, 且与价格趋势同向(都靠 BTC 长牛趋势)。

---

## ⚠️ 诚实的边界

- **Case B 不是独立 alpha**: 与价格趋势高度相关(0.94 vs 0.81), 增量仅 0.13 Sharpe。
  定位 = **BuyHold 的低回撤替代** (适合长期配置), 非纯 alpha 来源。
- **参数单点敏感**: 3月窗口最优(0.94), 6月骤降(0.69), 非 plateau, 别调优。
- **样本少**: 101 个月, 统计置信区间不窄。
- **Case A 信号B**: 互补有效但参数脆弱(hold=63 甜蜜点), 已决定不上线。
- **Case C**: 极值水位择时彻底证伪, 不再尝试。

## 🧭 决策与后续

**本次产出的可行动项**:
1. ✅ **Case B 月度动量配置** 可作为"长期持仓"参考层 — 若未来做资产配置产品再正式工程化
2. 🟡 Case A 信号B 留作研究池 (不上线)
3. 🔴 Case C 关闭

**Phase 3 整体定位**: 这是一次**方法论澄清**, 不是找到了印钞机。
最有价值的沉淀是"水位 vs 动量"铁律 — 它否定了大量"链上估值择时"的民间做法,
也给未来任何链上特征工程定了调: **优先做动量/方向变换, 别用绝对水位。**
