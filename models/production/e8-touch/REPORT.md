## 一、执行摘要

E8 是 E1 的「标签改进版」：把 directional（终点判定）换成 touch（路径触达），使标签语义与生产的 `--take-profit` 行为天然对齐。

**定位**：💰 **收益优先** —— 在可承受 ~21% 回撤的前提下，相对 E1 显著提高 CAGR 与 Sharpe。

| 维度 | 值 |
|------|------|
| 策略变体（生产） | **conservative** (止盈 + regime 过滤) |
| 回测 CAGR | 16.04% |
| 回测 MaxDD | -21.40% |
| 回测 Profit Factor | 1.28 |
| 回测 Sharpe | 0.76 |
| 平均暴露 | 23.3% |
| 模型类型 | LightGBM (129 特征，已去污染) |
| 与 E1 唯一差异 | **标签策略**（其余模型/特征/参数完全一致） |

**与 E1 的核心定位差异**：

| 维度 | E1 (directional) | E8 (touch) |
|------|------------------|------------|
| 标签语义 | 第 21 天 close ≥ +4% | 21 天内 high 曾触达 +4% |
| 与 TP 对齐 | ❌ 假设持有到期 | ✅ 路径触达即平仓（同构） |
| MaxDD | -12.7% | -21.4% |
| CAGR | 9.8% | 16.0% |
| 推荐 | 风控优先 | 收益优先 |

## 二、标签定义

### 2.1 标签策略: `touch_filtered`

**核心问题**：在「超卖低位」的市场状态下，未来 21 天 BTC 的**最高价**是否曾**触达**今日收盘价 +4%？

```python
# 条件 1: 当前处于超卖低位 (与 E1 一致)
rsi_14 < 45                 # RSI 低于 45
close < SMA_50              # 价格在 50 日均线下方

# 条件 2: 未来 21 天内路径触达 (与 E1 的关键差异)
max(high[t+1 : t+21]) >= close[t] * 1.04

# 标签
label = 1 if (条件 1 且 条件 2) else 0
```

**参数**（与 E1 完全相同）：

| 参数 | 值 | 含义 |
|------|------|------|
| T | 21 天 | 预测窗口 |
| X | 4% | 触达阈值 |
| rsi_window | 14 | RSI 计算窗口 |
| rsi_threshold | 45 | RSI 超卖分界线 |
| ma_window | 50 | 均线窗口 |
| require_below_ma | true | 必须在均线下方 |

### 2.2 与 E1 的标签差异（一个例子）

假设今天 BTC = $100，T=21，目标 $104：

```
Day  5: high = $106  ← 触达 $104 ✅
Day 21: close = $102 ← 终点只有 +2% ❌
```

| | E1 directional | E8 touch |
|---|---|---|
| 看什么 | Day 21 收盘价 | Day 1..21 最高价 |
| Label | **0** | **1** |
| 含义 | 拿到到期不够 +4% | 中途可以止盈 +4% |

### 2.3 去污染设计（与 E1 完全相同）

```yaml
drop_features:
  - rsi_*
  - price_vs_sma_*
  - sma_cross_10_50
  - sma_cross_50_200
```

模型从 137 个特征降至 **129 个**，避免标签过滤条件作为捷径特征被学习。

### 2.4 正例率与类别平衡

| 标签 | 正例率 | 类别比 | 任务难度 |
|------|--------|--------|----------|
| E1 directional | ~10% | 1 : 9 | 严重不平衡 |
| **E8 touch** | **~19%** | **1 : 4** | **较平衡** |

E8 的正例率提升源于「路径触达 ≥ 终点达成」，这也是 E8 离线分类指标看起来"全面碾压"E1 的主要原因。

> ⚠️ **关键提醒**：E8 与 E1 的 Kappa 不能直接比较！E8 的任务天然更容易。
> 真正的横向对比必须看 PnL（见 §5）。详见 `gpt_REVIEW.md` §2。

### 4.1 汇总指标

### 4.2 混淆矩阵

```
              预测=0    预测=1
实际=0       2712      138     (误报 138 次, FPR=4.8%)
```

vs E1（误报 241 / 捕捉 158 / 漏掉 206）：E8 在两端都显著更准，再次提示**任务本身更易**，不可直接归功于模型。

### 4.3 Walk-Forward Fold 稳定性

56 个 Fold 中：
- **F1 > 0 的 Fold**: 47 个 (**84%**)
- **Kappa > 0.5 的 Fold**: 44 个 (**79%**)
- **F1 = 0 的 Fold**: **9 个 (16%)** —— 集中在 fold 17-19, 35-36, 45-48

> ✅ **稳定性显著优于 E1**（E1 有 48% fold F1=0）。
> F1=0 集中在熊市低正例样本时段，与 E1 的失效区间高度重合 ——
> regime 过滤（§6）正是为屏蔽这些时段而设计。

### 5.3 敏感性分析（27 组合扫描）

来自 `experiments/.../sensitivity_report.md` 的关键结论：

**生产配置（Regime=-10%, Cost=0.1%, TP=4%）同时是**：
- 最高 Sharpe ✅
- 最高 Calmar ✅
- 最高总收益 ✅

**成本压力测试**（Regime=-10%, TP=4%）：

| 成本 | Return | Sharpe | MaxDD |
|------|--------|--------|-------|
| 0.1% | +64.3% | 0.76 | -21.4% |

→ 成本上升 3 倍时 Sharpe 衰减 21%，结构稳健。

→ -10% 是甜点，但与 -8% / -12% 差距明显，需注意**轻度过拟合风险**（仅 1 个超参点最优）。

## 六、策略变体原理（与 E1 完全相同）

### 6.1 层级关系

```
基础    = 模型信号 + 固定 21 天持仓
+止盈   = 基础 + 涨到 4% 即平仓
+regime = +止盈 + 63 天滚动收益 ≤ -10% → 熊市静默
```

### 6.2 保守版（生产版）每日决策流程

```
Step 1: Regime 判断
│  rolling_63d = (price_today / price_63d_ago) - 1
│
├─ rolling_63d ≤ -10%  →  熊市 → 强制空仓
└─ rolling_63d > -10%  →  非熊市 → 继续

Step 2: 持仓检查（已有仓位时）
├─ 浮盈 ≥ +4%       →  止盈平仓
├─ 持仓 ≥ 21 天      →  到期平仓
└─ 否则             →  继续持有

Step 3: 新信号（无仓位时）
├─ y_pred = 1  →  买入
└─ y_pred = 0  →  静默
```

### 6.3 为什么生产用 conservative 而不是 moderate？

`+止盈 (moderate)` 单变体的 Sharpe **1.02** 高于 conservative 的 **0.76**，但被否决，原因：

| 维度 | moderate | conservative | 决策依据 |
|------|----------|--------------|----------|
| Sharpe | **1.02** | 0.76 | moderate 胜 |
| MaxDD | -26.0% | **-21.4%** | conservative 胜 |
| 2022 熊市表现 | +21.6% (60% 暴露) | +1.3% (9% 暴露) | 看似 moderate 胜 |
| 熊市风险敞口 | 高 | 极低 | 风控胜 |

**结论**：生产部署遵循「与 E1 同口径」原则（两者都用 conservative），便于横向对比与混合组合。如未来调整为收益最大化优先，moderate 是值得提单独 review 的候选。

## 八、风险与局限性

### 8.1 已知风险

| 风险 | 说明 | 缓解 |
|------|------|------|
| **标签-策略同构** | touch 标签 ↔ TP 止盈结构相同，离线指标乐观 | 以 PnL 为最终判据，不看 Kappa |
| **回撤高于 E1** | -21.4% vs E1 -12.7% | 资金量大时优先 E1 |
| **回测周期短** | 仅 3.3 年 | paper trading 验证 |
| **牛市踏空** | 2023 仅 +0.36% | 策略定位是择时辅助，非替代持仓 |
| **Regime 甜点单点** | 仅 -10% 显著最优 | 监控线上 regime 命中分布，必要时重做扫描 |
| **manifest 旗标** | `no_data_leakage_suspicion: false` | 见 `gpt_REVIEW.md` §2 详释 |

### 8.2 不适用场景

- 纯牛市单边上涨（模型不出信号，超卖条件不满足）
- 高频交易（日线策略，平均 ~50 天一笔）
- 大资金主力仓位管理（仅作为择时信号）
- 对最大回撤极度敏感的产品（建议 E1）

### 8.3 健康监控建议（与 E1 同口径）

| 监控项 | 阈值 | 行动 |
|--------|------|------|
| 连续亏损笔数 | > 5 笔 | 暂停策略，重新评估 |
| 单笔亏损 | > -8% | 检查模型是否失效 |
| 月度回撤 | > -20% | 强制暂停（注意阈值比 E1 宽） |
| Regime 连续静默 | > 60 天 | 正常（熊市预期行为） |
| 信号密度漂移 | 月信号数 > 5 或 < 0.5 | 检查特征分布 |
